# Changelog

Все заметные изменения WM OS. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased] — третья итерация

### Изменено

* **Задачи и напоминания объединены в один экран «Дела»**
  * Экран «План» переписан в «Дела»: задачи и напоминания живут одним списком, сортировка — по
    времени срабатывания, безвременные — в конце. Напоминание и задача визуально едины, но каждая
    сохраняет свою «физику»: у задачи — круглый чекбокс (закрывается с отменой через снекбар), у
    напоминания — лаймовая круглая иконка будильника (тап по ней завершает напоминание).
  * Общие фильтры одним рядом чипов: Сегодня / Всё / Просрочено / Входящие / Готово — больше нет
    отдельной вкладки для напоминаний.
  * Карточка «Фокус дня» на фильтре «Сегодня»: сколько закрыто из запланированного, процент и
    глянцевый прогресс-бар.
  * Нижний лист создания «Новое дело»: Задача / Напоминание / Проект — одна точка входа.
  * Проекты — горизонтальная лента внизу списка «Всё» с прогрессом и карточкой «Новый проект»,
    отдельная вкладка больше не нужна.
  * Объединение сделано на уровне интерфейса: сущности БД, планировщик и редакторы
    (`Routes.task` / `Routes.reminder`) не тронуты — тап по строке открывает привычный редактор.
* **Редизайн по референсам (тёмный графит + lime, Apple-подобно)**
  * Главная: крупный заголовок «Собери моментум сегодня» с лаймовым словом, приветствие по времени
    суток, дата под заголовком.
  * Быстрые действия: [Заметка, Дела, Знания, Граус] вместо прежней четвёрки.
  * Прогресс дня: метрика «78%» справа, глянцевый лаймовый прогресс-бар, недельные столбики под ним
    (кольцевой индикатор с «Дома» убран).
  * Карточка Грауса стала светлой lime-градиентной с тёмным текстом («Твой AI-помощник», пилюля
    «Спросить»), как ассистентская плашка на референсах.
  * Нижняя навигация — плавающий док с центральной круглой лаймовой FAB Грауса: [Дом, Мозг,
    ● Граус, Дела, Ещё]. FAB с pressScale-поджатием и lime-свечением, пункты дока подсвечиваются
    выбранным состоянием. На экране чата графита док скрывается.
  * Иконка вкладки «Дела» — чеклист вместо календаря.
  * EmptyState: lime-круг с иконкой и пульсацией вместо серого.

### Сборка

* 51 юнит-тест зелёные, ktlint без замечаний, app-debug.apk ≈ 21.8 МБ.

## [Unreleased] — вторая итерация

### Исправлено (по батл-репорту с Groq)

* **«Модель тупая / я не умею это делать» на простое «пр»** — старый системный промпт прямо запрещал
  Граусу болтать («работаешь только с локальными данными»). Промпт переписан: свободное общение
  разрешено явно, правила по данным сохранены. Плюс стриминг и человеческая ошибка 402 из
  предыдущего комита.
* **Поле ввода чата ломалось при открытии клавиатуры** — вершина(Stack) обсчёта вставок: контент
  находился внутри Scaffold с нижним доком, а `imePadding()` добавлял ВЕСЬ размер клавиатуры
  поверх паддинга дока. Чат теперь фокус-поверхность: док на Граусе скрыт, подключён правильный
  chain `padding(inner) → consumeWindowInsets → navigationBarsPadding → imePadding`, стрелка
  «Назад» в шапке для возврата. Композер строго прижат к клавиатуре без двойных отступов.
* **«Кнопки пропадали, были пустые»** — реальный баг найден: модификатор `staggerAppear` стартовал
  элементы с `alpha = 0` и задержкой 45 мс × индекс — при скролле/на слабом железе плитки «Ещё» и
  другие ряды оставались полностью невидимыми. Модификатор удалён из проекта целиком, всё
  отрисовывается мгновенно.
* **Мёртвые элементы управления** — все оставшиеся `indication = null` заменены на ripple Material 3:
  плитки «Ещё», чекбокс задач, промо-карточка Грауса, док, карточки.

### Добавлено

* **Граус: живой стриминг чата**
  * AiClient.chatStream: ответ провайдера приходит потоково через SSE (`stream: true`), текст появляется
    сразу в растущей «пузырьковой» плашке, а не после 30–120 секунд молчания.
  * Стриминг работает и внутри инструментария: после срабатывания инструмента продолжение ответа
    тоже транслируется в чат по мере генерации (`GrausEngine.loop` → `onDelta`).
  * Разбор SSE вынесен в чистый, покрытый тестами `ChatStreamAccumulator` (текст, фрагменты
    аргументов tool-call, порядок вызовов по index, мусорные чанки игнорируются).
  * Ошибка HTTP 402 провайдера («Insufficient Balance») показывается по-человечески: «На балансе
    провайдера закончились средства», а не как загадочный сбой.
  * Системный промпт смягчён: Граус может свободно общаться и подбодрить, а не только работать с данными.
  * Экран чата переработан: приветствие с живыми чипами-подсказками (отправляются одним тапом),
    лаймово-графитовые пузыри сообщений, индикатор «Граус думает…», круглая кнопка отправки,
    убран шум (надпись про безопасность и заголовки «Граус» у каждого сообщения).
* **Тактильность интерфейса**
  * Убран «мёртвый тап»: `WmCard` и пункты нижнего дока получили ripple-отклик Material 3
    (раньше стоял `indication = null` — нажатие давало ноль визуального отклика, отсюда жалобы
    «кнопки пропадают»).
  * Иконка пункта дока дополнительно поджимается при нажатии.
  * Бесконечная пульсация пустых состояний замедлена и уменьшена по амплитуде — экономнее для
    слабых устройств.

### Добавлено (ранее)

* **Визуальная оболочка (третья итерация — UI/анимации)**
  * Плавные переходы между экранами: fade + slide-up для входа, обратная анимация при возврате.
  * Плавающий нижний док вместо стандартного `NavigationBar`: лаймовая «пилюля» у выбранной вкладки,
    анимированные масштаб иконки и переходы цвета, press-feedback.
  * Карточки (`WmCard`) сжимаются по spring-кривой при нажатии; списки анимируют появление
    (`staggerAppear`) и перестановку (`animateItem`) — Главная, План, Знания.
  * Главная: карточка «Прогресс дня» с анимированным кольцом процента и недельным бар-графиком
    продуктивности (данные из реально выполненных задач за 7 дней).
  * Промо-карточка Грауса с lime-градиентом; чипы-иконки в рядах напоминаний.
  * «Ещё»: плитки меню с цветными чипами (стиль референса), заголовки секций акцентным цветом.
  * «Ещё» и проекты: анимированные прогресс-бары с процентами вместо статичных индикаторов.
  * Пустые состояния: мягкая пульсация иконки.
* **Блокировка приложения (доведена до конца — ранее не подключалась)**
  * Добавлена зависимость `androidx.biometric:biometric:1.1.0` (из-за её отсутствия репозиторий не собирался).
  * MainActivity переведён на `FragmentActivity`, подключены `LockScreen`: PIN-клавиатура,
    разблокировка биометрией при поддержке устройства, блокировка при уходе в фон,
    счётчик попыток и lockout 30 с, переживают перезапуск процесса.
  * Настройки: диалоги «Настроить PIN», «Сменить PIN», «Отключить блокировку», переключатель биометрии.
    * **Задачи**
  * Отдельный экран задачи: название, описание, статус, приоритет, срок (дата + время),
    проект; создание и редактирование.
  * Undo после завершения задачи на Главной и в «Плане» (snackbar с кнопкой «Отменить»).
  * Подтверждение удаления задачи вместо мгновенного удаления.
* **Граус**
  * История диалогов: список, переключение, удаление с подтверждением.
  * Память фактов: просмотр, добавление, редактирование, удаление, пометка «чувствительное».
* **Backup**
  * Импорт JSON: разбор и валидация схемы, предпросмотр со счётчиками и конфликтами,
    режимы «Объединить», «Как новые» (новые ID с переносом ссылок), «Заменить» (с отдельным
    подтверждением), всё в одной транзакции.
* **Поиск**
  * Глобальный поиск по заметкам, задачам, напоминаниям, проектам и Входящим с указанием
    количества совпадений; доступен с Главной и из «Знаний».
* **Файлы**
  * Импорт через SAF прямо во Входящие (копия в приватное хранилище), плюс действия из share sheet.
  * Вложения к записям: выбор файла через SAF, копия в приватное хранилище (лимит 20 МБ),
    открытие через `FileProvider`, удаление копии без удаления оригинала.
  * Экран «WM Files»: список вложений с размером, типом и ссылкой на запись.
* **Autopilot**
  * Сценарии с ручным триггером и тремя разрешёнными действиями: сводка открытых задач и
    напоминаний в заметку, создание задачи, создание заметки.
  * Подтверждение запуска (по умолчанию включено), журнал действий, статус последнего запуска,
    защита от повторного запуска в течение 2 секунд.
  * Конфигурация валидируется до исполнения; неизвестное действие отклоняется.
* **Миграции БД**
  * Схема поднята до v2, добавлена явная миграция `MIGRATION_1_2` (таблица `automation_rules`),
    destructive fallback по-прежнему не используется.
* **Инфраструктура**
  * GitHub Actions: сборка, unit-тесты, выгрузка APK, отдельный job secret scanning (gitleaks).
  * `scripts/check-secrets.ps1` — локальная проверка репозитория на ключи.
  * ktlint 1.2.1 как настоящий гейт: `:app:ktlintCheck` падает на новых нарушениях,
    существующие зафиксированы в `app/ktlint-baseline.xml`, добавлен шаг в CI.

### Известные ограничения второй итерации

* Импорт не проверялся на чистом профиле вручную.
* CI-workflow в этой среде не запускался (нет git/runner).
* Миграция 1→2 написана по экспортированной схеме Room, но не проверена на устройстве с базой v1.
* По-прежнему нет: полного шифрования БД, PIN/биометрии, триггеров Autopilot по расписанию,
  OCR, семантического поиска, извлечения текста из PDF, detekt (ktlint есть).

## [0.1.0] — 2026-10-29

Первая зафиксированная версия. Ниже — только то, что действительно есть в коде;
нереализованные пункты вынесены отдельно.

### Добавлено

* **Данные**
  * Room-база `wm_os.db` (schema v1, WAL) с 14 таблицами: папки, записи, теги,
    связи тегов, задачи, проекты, напоминания, срабатывания, Inbox, диалоги,
    сообщения, AI-провайдеры, журнал действий, сохранённая память.
  * Репозитории для Second Brain, задач/проектов, напоминаний, Inbox, чата,
    провайдеров, журнала и экспорта.
  * Мягкое удаление записей в корзину, восстановление, окончательное удаление
    и очистка корзины.
  * Ревизии контента заметок и обнаружение конфликта при автосохранении.

* **Second Brain**
  * Заметки, памятки, ссылки, выдержки; необязательный заголовок.
  * Папки с защитой от циклов, подпапки, закрепление, архив.
  * Теги (нормализация, до 20 на запись), избранное.
  * Поиск по нижнему регистру заголовка и текста (кириллица работает).
  * Автосохранение с задержкой 600 мс, recoverable draft, финальный flush при
    уничтожении ViewModel.
  * Экспорт заметки в Markdown через системный Share Sheet.

* **Задачи и проекты**
  * Статусы `INBOX`, `NEXT`, `IN_PROGRESS`, `WAITING`, `DONE`, `CANCELLED`.
  * Приоритеты `LOW`, `NORMAL`, `HIGH`, `URGENT`.
  * Срок, описание, проект, soft delete.
  * Представления «Сегодня», «Предстоящие», «Просроченные», «Без срока»,
    «Входящие», «Выполненные».
  * Проекты с целью, описанием и прогрессом по реальным задачам.
  * Удаление проекта сохраняет задачи, снимая `projectId`.

* **Напоминания**
  * Одноразовые и повторяющиеся: DAILY, WEEKLY, MONTHLY, интервалы, дни недели,
    `CLAMP_TO_LAST_DAY` / `SKIP` для 29/30/31.
  * Разбор естественного русского текста: «завтра в 18:30», «через 45 минут»,
    «каждый понедельник в 10:00», «каждое 15 число».
  * Уточняющие вопросы вместо угадывания («вечером», диапазон, дата без времени).
  * AlarmManager: точные будильники при разрешении, неточные — с честным статусом.
  * Уведомления с действиями «Выполнено» и «Отложить на 10 минут».
  * Восстановление расписания после reboot, обновления приложения, смены зоны/времени.
  * Статусы `SCHEDULED`, `NOT_SCHEDULED`, `SNOOZED`, `FIRED`, `DONE`, `CANCELLED`,
    `MISSED`.

* **Inbox и Android Share**
  * Приём `text/plain`, URL, `image/*`, `application/pdf` через Share Sheet.
  * `PROCESS_TEXT` для выделенного текста.
  * Копирование файла в `filesDir/inbox` до любого анализа.
  * Явный статус `FAILED` при ошибке копирования.
  * Преобразование материала в заметку или задачу, удаление.
  * Переход на Inbox после Share через `openInboxSignal`.

* **AI Lab и Граус**
  * Свои OpenAI-совместимые провайдеры: OpenAI, DeepSeek, Groq, OpenRouter,
    custom (в диалоге AI Lab показаны 4 пресета; произвольный URL вводится вручную).
  * Хранение ключей в EncryptedSharedPreferences с мастер-ключом Android Keystore;
    в Room — только alias.
  * Маска ключа, проверка подключения, замена и удаление.
  * HTTPS-only, таймауты, типизированные ошибки (ключ, квота, rate limit, модель,
    контекст, сеть, сервер).
  * Чат Грауса с системным промптом и историей.
  * 7 инструментов: `get_app_capabilities`, `search_brain`, `read_brain_item`,
    `list_tasks`, `create_task`, `create_note`, `create_reminder`.
  * Подтверждение создающих действий через `PendingAction` и повторное чтение
    результата.
  * Журнал действий Грауса.

* **WM Quick**
  * Генератор паролей на `SecureRandom` (8–128 символов, классы символов).
  * Безопасный калькулятор без `eval`: `+ − * / %`, скобки, унарный минус.
  * Конвертер длины, массы и температуры.

* **Экспорт**
  * JSON со `schemaVersion`, папками, записями, задачами, проектами и напоминаниями.
  * Markdown-экспорт живых заметок.
  * SAF-выбор файла, статус успеха/ошибки, предупреждение об открытом тексте.

* **UI**
  * Пять вкладок: Главная, Знания, План, Граус, Ещё.
  * Экраны: Home, Brain, NoteEditor, Folder, Plan, Project, ReminderEditor,
    Graus, AI Lab, Inbox, Trash, ActionLog, Quick, Backup, Settings, About.
  * Тёмная и светлая темы, системная тема по умолчанию.
  * Графитовая палитра, лаймовый акцент, типографика под длинный русский текст.
  * Общие компоненты: `SectionHeader`, `EmptyState`, `LoadingState`, `WmCard`,
    `StatusPill`, `ConfirmDialog`, `WmListRow`.

* **Инфраструктура**
  * Ручной DI `AppContainer`, ViewModel-фабрики, UDF на `StateFlow`.
  * Room без destructive fallback, экспорт схемы в `app/schemas` (KSP).
  * 37 unit-тестов: recurrence, natural parser, quick tools — все проходят.
  * Проверочная сборка `:app:assembleDebug` — `BUILD SUCCESSFUL`, debug APK собран.

### Безопасность

* `allowBackup=false`; data extraction rules исключают БД, файлы, SharedPreferences
  и внешнее хранилище из cloud-backup и device-transfer.
* API-ключи не хранятся в Room, не логируются и не входят в экспорт.
* Только HTTPS для AI-провайдеров; проверка сертификатов не отключается.
* Нет аналитики, рекламных SDK, чтения буфера обмена и фонового сканирования.

### Не реализовано (P1)

* Импорт и восстановление backup; проверенный цикл restore на чистом профиле.
* Шифрованный backup и checksum/manifest.
* Полное шифрование базы/вложений/черновиков.
* Блокировка приложения PIN/биометрией, авто-блокировка, `FLAG_SECURE`.
* Вложения в редакторе заметки, SAF-импорт документов, извлечение текста PDF.
* Память Грауса (UI и использование `saved_memory`).
* Управление историей диалогов в UI (список, переименование, архив, удаление).
* Назначение моделей под задачи (чат/суммаризация/классификация), автопереключение.
* Полноценные подзадачи, экран задачи, этапы проекта, цели и привычки.
* Теги задач, фильтр по тегам, полнотекстовый/глобальный поиск.
* Тесты AI, Room, backup, уведомлений и Compose UI.

### Не реализовано (P2)

* Семантический поиск и локальные модели.
* OCR, сложный разбор PDF/документов, поиск дубликатов.
* Autopilot: триггеры, условия, preview, журнал, лимиты, отмена.
* Визуальный конструктор автоматизаций.
* Сравнение нескольких моделей, расширенные парсеры.
* История версий заметок, расширенные связи и шаблоны.
* WM Files: предпросмотр, история файловых операций, пакетная обработка.

### Известные проблемы

* Настройки «Компактные списки», «Отправлять текст заметок в контексте» и
  «Автопереключение провайдера» сохраняются, но не влияют на поведение.
* Нажатие на уведомление открывает приложение, а не конкретное напоминание.
* Кнопка «избранное» в экране папки не выполняет действие.
