# UX/UI спецификация WM OS

Документ фиксирует дизайн-систему и фактическое поведение экранов. Источники:
`ui/theme/Color.kt`, `Type.kt`, `Theme.kt`, `ui/components/Common.kt`,
`ui/nav/WmApp.kt`, `ui/screens/*`.

## 1. Визуальное направление

* Тёмная графитовая основа, светлый текст, сдержанный лаймовый акцент.
* Акцент используется для главного действия, выбранных состояний и ссылок, а не для
  раскрашивания всех элементов.
* Тёмная тема — основная; светлая реализована и переключается в настройках.
* Системная тема — значение по умолчанию (`ThemeMode.SYSTEM`).
* Карточки группируют блок, а не каждый абзац.
* Состояние никогда не передаётся только цветом: рядом есть текст и/или иконка.

## 5. Навигация

Пять вкладок нижней навигации:

| Вкладка | Маршрут | Иконка | Экран |
|---|---|---|---|
| Главная | `home` | Home | Сегодня, просроченное, напоминания, недавнее |
| Знания | `brain` | AutoStories | Second Brain |
| План | `plan` | CalendarMonth | Задачи, напоминания, проекты |
| Граус | `graus` | SmartToy | Чат |
| Ещё | `more` | MoreHoriz | Inbox, корзина, AI Lab, журнал, Quick, backup, настройки, About |

Правила:

* нижняя панель видна только на этих пяти маршрутах;
* на detail-экранах остаётся системная кнопка «Назад» и `TopAppBar` со стрелкой;
* переход между вкладками использует `popUpTo(startDestination) { saveState = true }`,
  `launchSingleTop`, `restoreState` — состояние вкладок сохраняется;
* повторное нажатие на выбранную вкладку ничего не делает;
* системный Back на detail-экране вызывает `popBackStack()`;
* редактор заметки не теряет черновик при уходе: `onCleared` пишет draft и финальную
  попытку сохранения в `appScope`.

## 6. Экраны

### 6.1 Главная

* Приветствие по времени суток: «Доброе утро» (5–11), «Добрый день» (12–17),
  «Добрый вечер» (18–22), «Ночная смена» (иначе).
* Быстрые действия: «Заметка», «Задача», «Напоминание», «Знания».
* Блок «Входящие» показывается только при `inboxNew > 0`.
* «Просрочено» — до 4 задач; «Сегодня» — до 6 задач; пустое состояние с CTA.
* «Ближайшие напоминания» — до 3; «Недавнее» — до 6 заметок.
* Карточка «Граус» с переходом в чат.
* Завершение задачи — иконка CheckCircle; повторное нажатие не предусмотрено
  (в Home только `completeTask(true)`).

### 6.2 Знания

* `TopAppBar` «Знания / Second Brain», меню: «Корзина», «Новая папка».
* Поиск по `searchText` (подстрока, без семантики).
* Чипы: Все, Заметки, Памятки, Ссылки, Избранное.
* Папки показываются только при пустом поиске/фильтрах.
* Создание: Заметка, Памятка, Ссылка, Папка.
* Карточка: иконка типа, заголовок или первая строка, сниппет, дата, звезда, удаление.
* Удаление — `ConfirmDialog` «Удалить в корзину?» с точной подписью.

### 6.3 Редактор заметки

* Большое поле заголовка (необязательное) и текста.
* Автосохранение с задержкой 600 мс; статус: «Сохранено», «Сохраняется…»,
  «Не сохранено», «Не удалось сохранить · Повторить».
* При конфликте ревизий — сообщение и сохранение текста в draft.
* При наличии более свежего черновика — диалог «Найден более свежий черновик»:
  «Восстановить черновик» / «Оставить сохранённое».
* Чипы папки и тегов; добавление тега, выбор папки, избранное, закрепление, архив.
* «Экспорт Markdown» отправляет текст через системный Share Sheet.
* Удаление — в корзину, не окончательное.

### 6.4 План

Три вкладки:

| Вкладка | Содержимое |
|---|---|
| Задачи | Фильтры «Сегодня», «Предстоящие», «Просроченные», «Без срока», «Входящие», «Выполненные» |
| Напоминания | «Предстоящие» и «Прошедшие и завершённые», кнопка «Выполнено» |
| Проекты | Карточки с `done/total` и прогресс-баром |

FAB меняется по вкладке: «Задача», «Напоминание», «Проект». Создание проекта
переиспользует диалог «Новая папка» (текст «Новая папка» — известное расхождение).

### 6.5 Напоминание

* Режимы «Текстом» / «Вручную».
* Natural-режим: поле фразы и живой preview (title, дата/время, warnings, вопрос).
* Ручной: title, description, дата, время, повтор, дни недели.
* Карточки разрешений: уведомления выключены / точные будильники запрещены.
* После сохранения — фактический статус: «Запланировано», «Запланировано неточно»,
  «Сохранено, но не запланировано».
* Удаление — destructive confirm «Удалить напоминание».

### 6.6 Граус

* Шапка: «Граус» + провайдер/модель или «Провайдер не настроен».
* Пустой чат: подсказка «Спросите что-нибудь по своим записям» и примеры.
* Сообщения: пузыри user/assistant, метка «Граус», время.
* Карточка `PendingAction`: заголовок, описание, preview, «Отменить» / «Подтвердить».
* «Что сделал Граус» — список tool notes.
* Ошибка — красная карточка с кнопками «AI Lab» и «Закрыть».
* Поле ввода и кнопка отправки; при `sending` — «Граус работает…».
* Внизу — пояснение, что запрос уходит выбранному провайдеру и ключ не передаётся модели.
* Нет списка диалогов, переименования, архива и удаления диалога в UI, хотя репозиторий
  это умеет.

### 6.7 Ещё

Секции «Материалы», «ИИ», «Инструменты», «Приложение»:

* Входящие (со счётчиком), Корзина;
* AI Lab, Журнал действий Грауса;
* WM Quick, Экспорт и backup;
* Настройки, О приложении;
* «Приватность» — **disabled**-строка, не кнопка-обманка.

### 6.8 Входящие

* Пустое состояние с CTA «Добавить материал».
* Ручное добавление текста/ссылки через диалог.
* Карточка: заголовок, сниппет, `kind`, дата, статус.
* Для NEW: «В заметку», «В задачу», «Удалить».
* Статусы: «Новое», «Разобрано», «Ошибка» — текстом + цветом.
* Материалы из Share попадают сюда автоматически; открытие экрана после Share
  обеспечивает `openInboxSignal`.

### 6.9 AI Lab

* Список провайдеров: имя, модель, base URL, маска ключа, переключатель enabled.
* Чипы: «Проверить», «Изменить», «По умолчанию», «Удалить».
* Диалог создания/редактирования: пресеты, имя, base URL (только https), модель, ключ,
  «Показать ключ», «Использовать по умолчанию».
* Результат проверки — карточка со статусом OK/Ошибка и текстом.
* Удаление — destructive confirm «Удалить провайдера».
* Нет выбора модели под разные задачи и нет автопереключения.

### 6.10 WM Quick

Три вкладки:

* «Пароль» — длина 8–64, цифры/символы/заглавные, SecureRandom, копирование, оценка;
* «Калькулятор» — безопасный рекурсивный парсер `+ − * / % ( )`, без eval;
* «Единицы» — длина, масса, температура.

### 6.11 Экспорт и backup

* Счётчики: папки, записи, задачи, проекты, напоминания.
* «Сохранить полный JSON», «Сохранить заметки в Markdown».
* Пояснение: ключи и пароли не попадают; файл дальше не контролируется приложением.
* Статус «Готово»/«Ошибка» с сообщением.
* Карточка «Импорт пока не реализован» — честная заглушка, не кнопка.

### 6.12 Настройки

* Тема: Системная / Тёмная / Светлая.
* «Компактные списки» — переключатель сохраняется, но **не влияет** на списки.
* «Отправлять текст заметок в контексте» — сохраняется, но **не читается** Граусом.
* «Автопереключение провайдера» — сохраняется, но логики автопереключения нет.
* «Корзина» — пояснение, что автоудаление не включено.
* Ссылка в системные настройки уведомлений.
* Переход «О приложении».

### 6.13 О приложении

Версия 0.1.0, список реально работающих модулей и честный список ограничений
(импорт, шифрование БД, блокировка, семантика/OCR/Autopilot, точность Android).

### 6.14 Корзина, папка, проект, журнал

* Корзина: восстановление, удаление навсегда, очистка с подтверждением и числом записей.
* Папка: описание, подпапки, материалы; создание подпапки; удаление записи в корзину.
  Кнопка «избранное» в списке папки — пустой обработчик (`onFavorite = { }`).
* Проект: цель, счётчик задач, прогресс, список задач, переключение статуса.
* Журнал: tool/status, summary, время; пустое состояние.

## 7. Состояния

| Состояние | Как показано | Где реализовано |
|---|---|---|
| Загрузка | `CircularProgressIndicator` / `LoadingState` | Home, NoteEditor, Graus, AI Lab, Backup |
| Пусто | `EmptyState` с CTA | Home, Brain, Plan, Inbox, Trash, Backup, AI Lab, ActionLog |
| Ошибка | Текст + «Повторить» | NoteEditor, Graus, AI Lab, Backup; `ErrorState` не используется |
| Офлайн | `OfflineBanner` объявлен, но не вызывается | — |
| Нет разрешения | Карточки уведомлений/exact alarm | ReminderEditor |
| Частичный успех | Статус `INEXACT` у напоминания, FAILED-запись Inbox | Reminder/Inbox |
| Сохранение | «Сохраняется…» / disabled-кнопка | NoteEditor, ReminderEditor, Backup |
| Отмена | «Отмена» в диалогах, «Отменить» в PendingCard | Везде |
| Конфликт | «Запись изменена в другом месте» | NoteEditor |

Пустые состояния обязаны предлагать действие. Примеры:

* «На сегодня задач нет» → «Добавить задачу»;
* «Здесь пока пусто» → «Создать заметку»;
* «Напоминаний нет» → «Создать напоминание»;
* «Корзина пуста» → без CTA (очищать нечего);
* «Провайдеров нет» → «Добавить провайдера».

## 8. Доступность

### 8.1 Размеры и фокус

* Ориентир — 48 dp для интерактивных зон.
* `IconButton` Material 3 даёт 48 dp; `WmListRow` — min 56 dp; FAB и кнопки выше 48 dp.
* `FilterChip` визуально ниже 48 dp; фактическая touch-зона зависит от
  `minimumInteractiveComponentSize` Material 3. Отдельных измерений и UI-тестов нет.
* Все списки — `LazyColumn`/`LazyRow`, длинный текст переносится или обрезается
  `maxLines` + ellipsis.
* Системный масштаб шрифта используется (`sp`), но тестов на максимальный font scale нет.

### 8.2 Семантика

* У большинства `IconButton` есть `contentDescription` («Назад», «Удалить»,
  «В избранное», «Отправить» и т. д.).
* Декоративные иконки имеют `contentDescription = null` — это правильно, если текст
  рядом уже описывает действие.
* `StatusPill` всегда содержит текст, цвет — дополнительный сигнал.
* `ConfirmDialog` называет последствие в подписи кнопки, а не «ОК».
* Нет `TalkBack`-тестов и явных `semantics` для кастомных карточек, кроме
  `Modifier.accessibleClick()` (объявлен, но в экранах не используется).

### 8.3 Контраст

* `Ink100` на `Graphite900` — высокий контраст.
* `Ink300` на `Graphite800` — вторичный текст; на мелких размерах может быть ниже AA,
  отдельного аудита нет.
* Лаймовый `Lime` на `Graphite900` — высокий контраст; `OnLime` на `Lime` — тёмный текст.
* Светлая тема использует `LimeOnLight` для primary, а не яркий `Lime`, чтобы сохранить
  контраст.
* Цвет не единственный носитель статуса: везде есть подпись.

## 9. Опасные действия: формулировки

Правило: кнопка подтверждения повторяет последствие, а не «ОК».

| Действие | Заголовок | Кнопка подтверждения | Отмена |
|---|---|---|---|
| Заметка → корзина | «Удалить в корзину?» | «Удалить в корзину» | «Отмена» |
| Заметка из редактора | «Переместить в корзину?» | «В корзину» | «Отмена» |
| Заметка в папке | «В корзину?» | «В корзину» | «Отмена» |
| Окончательное удаление | «Удалить навсегда?» | «Удалить навсегда» | «Отмена» |
| Очистка корзины | «Очистить корзину?» | «Удалить навсегда» | «Отмена» |
| Удаление напоминания | «Удалить напоминание?» | «Удалить напоминание» | «Отмена» |
| Удаление провайдера | «Удалить провайдера?» | «Удалить провайдера» | «Отмена» |
| Отмена действия Грауса | — | — | «Отменить» |

Тексты подтверждений объясняют обратимость: «можно будет восстановить из корзины»,
«нельзя будет восстановить», «запланированный сигнал будет отменён».
Массовая очистка корзины показывает число записей.

## 10. Обратная связь и защита от двойного нажатия

* `ReminderEditorScreen`: кнопка сохранения disabled при `saving`; после успеха
  показывается фактический precision.
* `BackupScreen`: кнопки disabled при `busy`.
* `GrausScreen`: отправка disabled при пустом вводе, `sending` или отсутствии провайдера;
  текст очищается сразу после нажатия.
* `AiLabScreen`: проверка подключения не блокирует кнопку — можно запустить несколько
  проверок; результат общий.
* `NoteEditorScreen`: автосохранение сериализуется через `saveJob`; ручной retry доступен.
* `HomeScreen`: быстрое создание задачи не блокирует диалог; повторное нажатие может
  создать дубль (идемпотентности нет).

## 11. Известные расхождения с ТЗ

1. Нижняя вкладка называется «План», а не «Задачи»; внутри есть задачи, напоминания,
   проекты.
